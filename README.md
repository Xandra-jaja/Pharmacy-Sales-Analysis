Pharmacy Sales Analysis

Project Overview

This project focuses on analysing pharmacy sales data to uncover meaningful business insights, understand sales performance, and identify trends that can support better business decisions.

The analysis was carried out using Microsoft Excel, SQL, and Power BI, covering different stages of the data analysis process, from data preparation to querying, analysis, and visualisation.

Project Objectives

The main objectives of this project were to:
	•	Evaluate overall pharmacy sales performance.
	•	Analyse revenue and sales trends.
	•	Identify top-performing products.
	•	Examine sales performance across different countries.
	•	Evaluate salesperson performance.
	•	Identify patterns and trends that can support business growth.
	•	Provide data-driven recommendations for improving sales performance.

Tools and Technologies
	•	Microsoft Excel: Data cleaning, preparation, and exploration.
	•	SQL: Data querying, manipulation, and analysis.
	•	Power BI: Data visualisation, dashboard development, and reporting.

Key Areas of Analysis
	•	Total Revenue
	•	Units Sold
	•	Total Transactions
	•	Average Order Value
	•	Revenue by Product
	•	Revenue by Country
	•	Sales Trends Over Time
	•	Salesperson Performance

Project Workflow
	1.	Data preparation and cleaning using Excel.
	2.	Data querying and analysis using SQL.
	3.	Data visualisation and dashboard development using Power BI.
	4.	Interpretation of results and identification of business insights.
	5.	Development of recommendations based on the analysis.

Dashboard Preview

The Power BI dashboard provides a visual overview of pharmacy sales performance, helping users explore important business metrics and identify sales patterns.

Conclusion

This project provided an opportunity to apply my skills in Excel, SQL, and Power BI to a practical business analysis task.

It strengthened my understanding of the data analysis process and demonstrated how data can be transformed into meaningful insights to support business decisions.
